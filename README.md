# 🔥 INFERNO Barbershop

A premium, fully responsive landing page for a men's barbershop. Built with a focus on modern Dark UI/UX, high performance, and interactivity.

🔗 **Live Demo:** [https://aleksshaparyuk.github.io/inferno-barbershop/](https://aleksshaparyuk.github.io/inferno-barbershop/)

---

### 🇧 English Version

#### 🚀 Features
- 📱 **Fully Responsive:** Mobile-First approach using CSS Grid and Flexbox.
- 🌍 **Language Switcher:** Instant RU/EN translation without page reload (Vanilla JS).
- 🎨 **Dark UI:** Deep black color scheme with fiery red accents using CSS variables.
- 🗺️ **Custom Map:** Google Maps styled via CSS filters to match the dark theme.
- ⚡ **Interactive:** Smooth hover animations and a working feedback form.

####  Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, CSS Grid, Custom Properties, Media Queries, CSS Filters)
- **JavaScript (Vanilla)** (DOM manipulation, Event Listeners, Object-based localization)

#### ⚙️ How it works
- **Localization:** All text is stored in a JS object dictionary. Clicking the language buttons triggers a function that updates the DOM elements based on `data-i18n` attributes.
- **Map Styling:** The embedded Google Maps iframe is transformed into a dark map using CSS `filter: grayscale(100%) invert(92%) contrast(83%);`.

### 🇷🇺 Русская версия

#### 🚀 Особенности проекта
-  **Полная адаптивность:** Подход Mobile-First с использованием CSS Grid и Flexbox.
- 🌍 **Переключение языков:** Мгновенный перевод RU/EN без перезагрузки страницы (чистый JS).
- 🎨 **Темная тема:** Глубокий черный фон с огненно-красными акцентами через CSS-переменные.
- 🗺️ **Кастомная карта:** Google Maps стилизован через CSS-фильтры под общий дизайн сайта.
- ⚡ **Интерактивность:** Плавные анимации и рабочая форма обратной связи.

#### 🛠 Использованные технологии
- **HTML5** (Семантическая верстка)
- **CSS3** (Flexbox, CSS Grid, кастомные свойства, медиа-запросы, CSS-фильтры)
- **JavaScript (Vanilla)** (Манипуляция DOM, обработка событий, локализация через объекты)

#### ⚙️ Как это работает
- **Локализация:** Весь текст хранится в JS-объекте (словаре). При клике на кнопки языка функция находит элементы по атрибуту `data-i18n` и подменяет текст.
- **Стилизация карты:** Встроенная карта Google превращается в темную с помощью CSS-свойства `filter: grayscale(100%) invert(92%) contrast(83%);`.
